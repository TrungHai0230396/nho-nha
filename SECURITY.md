# Báo lỗ hổng bảo mật

Thấy lỗ hổng trong code này hay trong bản đang chạy ở https://nho-nha.pages.dev, xin báo riêng qua nút **Report a vulnerability** ở tab **Security** của repo, đừng mở issue công khai. Ghi rõ chỗ nào, cách lặp lại và ảnh hưởng tới đâu.

Phạm vi: code trong repo này và bản ở nho-nha.pages.dev. Xin đừng đụng vào dữ liệu của người khác, đừng làm app ngừng chạy (app chạy trên gói miễn phí của Cloudflare, hạn mức nhỏ) và đừng gửi thư rác.

## Reporting a vulnerability

If you find a vulnerability in this code or in the instance at https://nho-nha.pages.dev, please report it privately with **Report a vulnerability** on this repository's **Security** tab, not in a public issue. Say where it is, how to reproduce it and what it affects.

Scope: the code in this repository and the instance at nho-nha.pages.dev. Please do not access other people's data, degrade the service (it runs on Cloudflare's free plan, with small quotas) or send spam.
